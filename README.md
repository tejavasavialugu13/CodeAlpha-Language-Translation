🌐 AI Language Translation Tool

Project Description

The AI Language Translation Tool is a Python-based web application developed as part of the CodeAlpha Artificial Intelligence Internship. It helps users translate text between different languages through a simple and user-friendly interface.

Features

- Supports multiple languages.
- Automatic language selection.
- Translate text between selected languages.
- Copy translated text.
- Translation history.
- Clear translation history.
- Simple and interactive interface.

Technologies Used

- Python
- Streamlit
- Requests
- MyMemory Translation API

Installation and Setup

1. Clone the repository:

git clone https://github.com/tejavasavialugu13/CodeAlpha-Language-Translation.git

2. Open the project folder:

cd CodeAlpha-Language-Translation

3. Install the required libraries:

pip install streamlit requests

4. Run the application:

streamlit run app.py

How to Use

1. Open the application in your browser.
2. Select the source language.
3. Select the target language.
4. Enter the text you want to translate.
5. Click the Translate button.
6. View and copy the translated text.
7. Check your translation history.
